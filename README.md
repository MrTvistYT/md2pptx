# md2pptx
> _Markdown to PowerPoint presentation converter_
> 
> by Oleksandr Buts

## Бекенд
### Эндпоинты

> **POST**
> 
> `/generate` - Формирует презентацию 
> - Принимает json (схема - [CreatePresentation](#createpresentation))
> - Возвращает application/pptx

### Движок обработки презентаций

> `PresentationGenerator` - Класс, который используется для формации контента презентации на основе прочтённого контента.
> 
> Включает в себя:
> - экспорт презентации (`export()`- возвращает сохранённую презентацию в памяти ОЗУ)
> - наполнение презентации (`unparse()` - создаёт презентацию из текста)
 
> `ContentReader` - Класс, который используется для обработки внутренней информации
> 
> Включает в себя:
> - разбивку на условные слайды (`slides_data()` - возвращает список строк слайда).
> - выявление типа слайда (`define_slide_type()` - выявляет количество элементов + возвращает тип слайда (класс наследующий Slide)

#### Слайды
> `Slide` - Интерфейс, который позволяет добавить слайд в презентацию
> 
> add_to_presentation()` - метод для добавления на презентацию

> TitleSlide - Класс, наследующий Slide. 
> 
> Хранит параметры:
> - `title`
> - `subtitle`
>
> Реализует интерфейс:
> 1) добавляет титульный слайд
> 2) берёт его элементы
> 3) заполняет текстом

### Схемы
#### CreatePresentation
> `presentation_name` - название файла презентации
> 
> `content` - контент презентации
